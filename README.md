# FiveM-EventPool
`by Ghost @ FNGS / 2026` → [Author's GitHub](https://github.com/GhostQck) / [Publish Github](https://github.com/FNGS-Gh)

This script is more of a showcase implementation. It is completely standalone and might be useful only during the development process. The script periodically (every 100 ms) checks a set of player states and triggers a corresponding custom client event if the state mutates. For optimization and standard production purposes, it is best to strip away any excessive events and use only those that cause any reaction in 2 or more resources.
